# Notch

אפליקציה למק שיושבת על החריץ ומראה את הצ'אטים של Claude Code ו-Codex: מי עובד, מי סיים ומי מחכה לך. משם אפשר גם לאשר בקשות הרשאה, לשמור קבצים במגש ולשלוח באיירדרופ.

## הורדה

**[להורדת הגרסה האחרונה](https://github.com/erelfridman/notch-releases/releases/latest/download/Notch.dmg)**

צריך מק עם שבב של אפל (M1 ומעלה) ו-macOS 14 ומעלה.

## התקנה

1. פותחים את הקובץ שירד וגוררים את Notch לתיקיית Applications.
2. בפתיחה הראשונה macOS יגיד שהוא לא יכול לאמת את המפתח, כי האפליקציה עוד לא חתומה אצל אפל. סוגרים את ההודעה, נכנסים להגדרות המערכת ← פרטיות ואבטחה, גוללים למטה ולוחצים "פתח בכל זאת" (Open Anyway). זה רק בפעם הראשונה.
3. מאשרים את תנאי השימוש.
4. האפליקציה מציגה "קוד מחשב". שולחים אותו לאראל, ומקבלים בחזרה קוד הפעלה שעובד רק במחשב הזה. מדביקים ולוחצים "הפעלה".

בלי קוד הפעלה האפליקציה לא עושה כלום.

## עדכונים

פעם ביום האפליקציה בודקת אם יצאה גרסה חדשה ומציעה להתקין אותה. אפשר גם לבדוק ידנית: בתפריט של Notch בשורת התפריטים ← "בדיקת עדכונים…".

## פרטיות

הכל רץ על המחשב שלך. האפליקציה מתחברת לאינטרנט רק כדי לבדוק עדכונים בדף הזה. הפירוט המלא נמצא במדיניות הפרטיות, בתוך האפליקציה: הגדרות ← אודות.
